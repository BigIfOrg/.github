## If true, what then?

**Big If True** is an open Discord community for people who follow the news closely and still want to argue about what it means. We cover world events, markets, politics, technology, crypto and whatever else is worth discussing.

> A claim should have a source. A disagreement should have a reason. A good question should make room for another one.

Reporting is where we start. Members follow the sources, challenge the take, watch together, and see what comes next:

1. **Read the reporting.** A live news desk groups coverage of the same event into one source-backed story.
2. **Talk it through.** Every story gets its own Discord thread, along with topic channels for World, Markets, Politics, Technology and Crypto.
3. **See where it leads.** Daily games, Watch Nights and four companion bots keep the conversation going after the headline.

Curiosity is a team sport. **[Come find the thread →](https://discord.gg/bigiftrue)**

## Four voices. One universe.

The server runs on four bots we build in-house. They share a design language, a login on [bigif.org](https://bigif.org), and in three cases a common AI runtime.

<table>
  <tr>
    <td width="120" align="center" valign="top">
      <img src="https://bigif.org/assets/bots/big.png" alt="Big" width="96" /><br />
      <strong>Big</strong><br /><sub>The Editor</sub>
    </td>
    <td valign="top">
      <strong>A live news system for Discord forum channels.</strong> Big reads RSS/Atom, Reddit and X feeds and groups reports from many publishers about one event into a single story. Each story gets one forum post, which keeps updating as new sources and developments arrive.
      <ul>
        <li><strong>Event clustering.</strong> Coverage is matched on what actually happened, not just similar headlines. Stories move through <code>NEW → DEVELOPING / BREAKING → UPDATED → STALE</code> and can be merged or split.</li>
        <li><strong>Factual summaries.</strong> Each summary is split into <em>Summary · Key facts · Context · Unclear or disputed · Sources</em>. Citations are checked against the stored articles, and opinion is not allowed.</li>
        <li><strong>Quality gate.</strong> Opinion pieces, podcasts and filler are held back. Posts are auto-tagged, related stories are linked, and article photos keep their original credits.</li>
        <li><strong>Top Stories.</strong> A pinned roundup in each forum, refreshed hourly and mirrored on <a href="https://bigif.org/news/">bigif.org/news</a>.</li>
        <li><strong>Right-click tools.</strong> <em>Summarize Article</em> runs any link through the pipeline. <em>Fact Check</em> rates claims as True, Mostly True, Misleading, False, Unsupported or Unclear, backed by evidence from the web.</li>
        <li><strong>News chat.</strong> Ask Big about current events with <code>?ask</code>, a mention or a reply.</li>
        <li>It also powers the <a href="https://bigif.org/daily/">Big Daily</a> game and the public story API behind the website.</li>
      </ul>
    </td>
  </tr>
  <tr>
    <td width="120" align="center" valign="top">
      <img src="https://bigif.org/assets/bots/custodian.png" alt="Custodian" width="96" /><br />
      <strong>Custodian</strong><br /><sub>The Host</sub>
    </td>
    <td valign="top">
      <strong>Moderation, security and server life. It "catches scammers before they catch your members."</strong>
      <ul>
        <li><strong>Containment.</strong> A member reports a suspicious account and a moderator contains it with one click. Custodian removes the account's roles, confines it to a holding channel, captures evidence and links related accounts. Released members get their roles back. To get out, the account has to pass an escape room: a CAPTCHA plus a reflection wait.</li>
        <li><strong>Threat assessment.</strong> A 0–100 risk score, backed by evidence for each signal. Optional, anonymous cross-server reputation is shown only when enough independent communities agree.</li>
        <li><strong>Security suite.</strong>
          <ul>
            <li>Anti-nuke and anti-raid protection.</li>
            <li>A scam link filter that catches typosquats, homoglyphs and IP grabbers.</li>
            <li>Smart dehoisting of impersonators.</li>
            <li>Covert-promotion detection.</li>
            <li>Bot permission monitoring.</li>
            <li>An offline anti-malware scanner that reads QR codes and uses OCR, without uploading anything to third parties.</li>
          </ul>
          It never asks for Administrator.</li>
        <li><strong>Transparent moderation.</strong> A categorized, hash-chained (tamper-evident) mod log. In Big If True, the moderation and containment logs are open to members, so anyone can see what action was taken and why.</li>
        <li><strong>Community.</strong>
          <ul>
            <li>Leveling with rendered rank cards, streaks and role rewards.</li>
            <li>Giveaways, polls and predictions.</li>
            <li>Sticky, booster and event roles, and an automation builder.</li>
            <li>Vote rewards and server backups.</li>
          </ul>
        </li>
        <li><strong>Watch Nights.</strong> Staff-hosted anime, movie and TV nights with queues, RSVPs, suggestions, votes and attendance rewards.</li>
      </ul>
    </td>

      <strong>The AI companion of the server: curious, direct, well-read, lightly playful and occasionally dry.</strong> Disco follows the community standard: check sources, disagree freely and explain why, and correct bad information, including its own.
      <ul>
        <li><strong>Conversation with memory.</strong> Disco answers mentions, replies and <code>,ask</code>, and remembers past conversations through semantic search. Thinking, searching, reading sources and generating all appear in one live message that edits in place.</li>
        <li><strong>Research.</strong> Disco searches the web and reads articles, then cites its sources. A deeper <em>Try Harder</em> mode handles questions that need more digging. It can also search Big's published stories directly.</li>
        <li><strong>Vision and images.</strong> Disco describes the images and GIFs you show it, and can generate new images.</li>
        <li><strong>Threads.</strong> Conversations can be saved, linked, grouped, searched and resumed with <code>,thread</code>.</li>
        <li><strong>Extras.</strong> A <em>DEFCON</em> world-tension reading graded from live headlines, song lookups, and a sandboxed private workspace for trusted users.</li>

## Under the hood

For developers who like to know how things work:

```text
                         ┌──────────────────────────────┐
                         │          bigif.org           │
                         │  static HTML/CSS/JS · no     │
                         │  trackers · Discord login    │
                         └──────────────┬───────────────┘
                                        │ story API · daily · watch
        ┌──────────────┬────────────────┼──────────────────┬───────────────┐
        │              │                │                  │               │
   ┌────▼────┐   ┌─────▼─────┐     ┌────▼────┐       ┌─────▼────┐    ┌─────▼─────┐
   │   Big   │   │ Custodian │     │  Disco  │       │  Ticker  │    │  Jellyfin │
   │ Python  │   │  Python   │     │ Python  │       │ Node.js  │    │  (Watch   │
   │ SQLite  │   │ Postgres  │     │ Postgres│       │ Postgres │    │  Nights)  │
   └────┬────┘   └───────────┘     └────┬────┘       └─────┬────┘    └───────────┘
        │                               │                  │ (Python AI adapter)
        └───────────────────────────────┴─────────┬────────┘
                                       ┌──────────▼───────────┐
                                       │  Shared AI framework │  policy · tools · research ·
                                       │  (Postgres + Redis)  │  one weekly credit ledger
                                       └──────────────────────┘
```

- **Big:** Python 3.11+, discord.py, aiohttp, SQLite with versioned migrations, and feedparser. It runs in Docker as a non-root user on a read-only filesystem.
- **Custodian:** Python, discord.py, PostgreSQL and a FastAPI REST API. The offline scanning stack is Pillow, zxing-cpp and Tesseract. Its dashboard is TanStack Start (React 19, SSR) in TypeScript.
- **Disco:** Python 3.12, discord.py with the Components V2 UI, PostgreSQL via asyncpg, and Redis/Valkey. Private workspace commands run in a Bubblewrap sandbox.
- **Ticker:** Node.js and discord.js v14, with Puppeteer for chart rendering, ccxt for exchange data, and PostgreSQL. A small Python adapter connects it to the shared AI framework.
- **Website:** framework-free static pages with self-hosted fonts and no tracking scripts, served through nginx or Cloudflare Pages.
- **Shared AI layer:** Big, Disco and Ticker share one AI runtime that handles model policy, tool calling, bounded web research with citation checks, and a single weekly credit ledger. Models are routed through OpenRouter, with zero-data-retention routing where it's available.
- **Engineering norms across the projects:** Docker everywhere, CI on GitHub Actions (ruff, mypy, pytest, `node --test`), forward-only migrations, and least-privilege bot permissions.
